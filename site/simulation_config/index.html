Simulation Parameters¶

MultipleSusis pydantic-model ¶

Bases: BaseModel

Highest abstraction layer for the input parameters.

Enables the creation of multiple SUSI simulations.

Fields:

  • n_parallel_processes (PositiveInt)
  • simulation_parameter_list (list[SimulationParams])

Validators:

  • validate_configuration

n_parallel_processes pydantic-field ¶

Number of parallel processes to spawn. Cannot be greater than the number of simulations. Must be higher than 1, 40 at most (40 is the maximum number of cores in a single node, at least in CSC).

simulation_parameter_list pydantic-field ¶

A list of parameters fully specifying each run. The length of the list determines the number of simulations than will be run, regardless of how many parallel processes are specified in n_parallel_processes. E.g., a simulation_parameter_list of length 2 will execute 2 full susi runs no matter the number of parallel processes specified (which in such case can only be either 1 or 2).

validate_configuration() pydantic-validator ¶

Validate the entire model after all fields are set.

SimulationMetaData pydantic-model ¶

Bases: BaseModel

Config:

  • validate_default: True

Fields:

  • metadata_schema_version (int)
  • metadata_output_filename (str)
  • parameter_output_filename (str)
  • netcdf_output_filename (str)
  • timestamp_start (str)
  • timestamp_end (str)
  • git_commit_hash (str)
  • host_info (str)
  • experiment_name (str)
  • experiment_folder_path (Path | None)

Validators:

  • check_json_extension → metadata_output_filename, parameter_output_filename
  • check_netcdf_extension → netcdf_output_filename
  • set_experiment_folder_path

experiment_folder_path = None pydantic-field ¶

Directory Path for all simulation results: metadata, parameters, and netcdf file. If None (default), the folder name is the same as experiment_id.

experiment_id cached property ¶

A string that uniquely identifies each simulation experiment. If None, it is computed as a combination of the starting timestamp and a random number to avoid naame collisions.

experiment_name = '' pydantic-field ¶

A name for the experiment. It defaults to the empty string. This field will be used to create the folder where Susi outputs are stored. Susi automatically attaches the starting date/time and a random string to each folder name to avoid name collisions.

git_commit_hash pydantic-field ¶

Git commit identifier.

host_info = str(platform.uname()) pydantic-field ¶

Info about who ran the simulations.

metadata_output_filename = 'metadata.json' pydantic-field ¶

Name of the output metadata file. Needs to be JSON. It will be stored inside the experiment_folder_path.

netcdf_output_filename = 'susi.nc' pydantic-field ¶

Name of the output netcdf file. Needs to have extension '.nc'. It will be stored inside the experiment_folder_path.

parameter_output_filename = 'params.json' pydantic-field ¶

Name of the output parameters file. Needs to be JSON. It will be stored inside the experiment_folder_path.

timestamp_end = str() pydantic-field ¶

Final timestamp, recorded when the metadata dumping is done.

timestamp_start pydantic-field ¶

Initial timestamp. (Technically, it takes the timestamp at the time the current class is created).
